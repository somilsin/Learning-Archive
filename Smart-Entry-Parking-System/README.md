## 📖 About This Repository

I used an Arduino to build a small parking gate prototype. A registered RFID card opens the servo gate, while a Bluetooth command allows guest entry.

---

## 🚀 Key Implementations

* Registered card authentication
* Servo gate control
* Bluetooth guest entry

---

## 🎓 Project Guide

### Hardware

* Arduino Uno
* MFRC522 RFID reader and cards
* Servo motor
* HC 05 Bluetooth module

The Serial Monitor displays the card UID while working through the card checks.

### How it works

The Arduino checks a card ID and controls the servo gate. A Bluetooth command provides the guest entry path.

### Ideas to try

The earlier notes include WiFi monitoring, entry logs, a dashboard and camera based plate checks as possible extensions.
