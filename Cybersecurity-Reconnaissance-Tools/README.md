## 📖 About This Repository

I explored network reconnaissance through remote OS discovery and open port detection. This folder keeps the Python code and the SQLite port mapping database.

---

## 🚀 Key Implementations

* Network discovery code
* Port detection and mapping
* A SQLite database with supporting data

---

## 🎓 Project Guide

### The code

* [remote_os_detection.py](src/remote_os_detection.py) for OS discovery.
* [open_port_scanner.py](src/open_port_scanner.py) for port scanning.
* [commands/](src/commands/) for the command handlers.
* [portmap.db](portmap.db) for port mapping data.
* [requirements.txt](requirements.txt) for the saved dependency list.

### What I explored

Remote OS discovery, open port detection and storing port mapping data in SQLite.
